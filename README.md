Una aplicacion donde usamos un falso login y logout para acceder a nuestra lista de TODO-APP
donde simulamos peticiones HTTP, uso de async/await, uso de localStorage para mantener la 
informacion del usuario almacenada segun lo que escriba en la lista,
usos de eventos para hacer dinamica la lista con agregar, completar, eliminar.
manipulacion del DOM y UI desde JavaScript,
uso de libreria externa de bootstrap para mejorar el diseño,
uso de libreria sweetalet para mejorar el diseño y la experiencia del usario al capturar algun error,
arquitectura limpia y codigo limpio de javascript.
